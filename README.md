# 蒋欢与江婕的新婚晚宴请帖

请帖：[打开请帖](https://jianghuan3658.github.io/wedding-invitation/)

管理：[报名管理页](https://jianghuan3658.github.io/wedding-invitation/admin.html)

首页采用暖棕盘发婚纱照的满屏婚礼海报，白色斜体标题与新人姓名、日期、开席时间叠在照片下半部；正文采用奶油白、酒红点缀的摄影画册排版。婚宴为 2026 年 11 月 7 日 17:18，地址是浙江省杭州市临安区太湖源镇界牌头29号。年份按当前年度配置。

## 照片与音乐

新人选择的盘发版素材共 12 个系列、73 张，全部保留。使用 480、960、1600 像素宽的 WebP 衍生图片，原文件未改动。首页封面选用暖棕经典-006，在手机中以居中满屏裁切展示，保证两人脸部完整；相册保留完整原构图。系列以横向摄影画册展示，点封面直接进入全屏照片册，通过原生横向滚动、细缩略图、按钮或键盘翻阅；细节模式锁定翻页，退出后回到封面及原浏览位置。所选系列才加载大图。箭头使用单色 SVG 细线图形，避免平台将字符渲染成蓝色 emoji。浏览器横向滚动与手机尺寸已验证，真机触屏尚待验收。

`data/wedding.json` 保存姓名、婚期、时间、地址及音频路径。`music.src` 当前为空，等待新人提供音频。提供音频后尝试自动播放；浏览器限制时通过一次“开启请帖”操作播放，并提供暂停、继续和跳过入口。

## 回执与私人统计

回执收集姓名和含本人的用餐人数。管理页支持登录后查看报名组数、总用餐人数、明细、同名提示和 CSV 导出；同名不直接合并。宾客在同一浏览器重新提交会更新本人报名。

后端为独立 Supabase 免费项目（新加坡），使用匿名访客身份、数据库事务和私人管理员权限。2026 年 10 月 7 日已绑定实际数据库，提交成功后才显示收到回执。前端不再调用腾讯云，不向公开仓库保存报名名单、账号密码或服务密钥。

数据库 SQL、权限配置与验收范围见 [backend/supabase/README.md](backend/supabase/README.md)。实际匿名提交、管理登录与实时通知已验证；管理页使用实时监听及每 5 秒校对，支持查看、搜索、导出，退出登录会清除页面中的名单和统计。数据库默认域名的国内直连存在部分线路失败，正在补充独立访问路径；当前测试成功的浏览器和 SDK 使用了代理，不能据此宣称免 VPN 验收完成。
